# Публикация NOVA в GitHub Pages

1. Создать публичный `PROAiCRM/nova-music-studio` с README (см. владельческую инструкцию).
2. Загрузить `index.html` и проектные документы в `main`, не добавляя секретов или личного аудио.
3. В репозитории открыть **Settings → Pages**.
4. В поле Source выбрать **Deploy from a branch**.
5. Выбрать `main` и `/(root)`, нажать **Save**.
6. Проверить реальное сообщение Published и открыть HTTPS-ссылку из Pages. Не путать предполагаемый URL с подтверждённой публикацией.
7. Сделать резервную копию из старого адреса NOVA → импортировать её на постоянном адресе. Разные домены имеют отдельную IndexedDB.

GitHub Pages статический: он не выполняет серверный код и не предназначен для хранения приватных аудио. Для этого нужен отдельный сервер/приватное хранилище.
