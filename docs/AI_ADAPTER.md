# NOVA AI provider-neutral boundary (не реализовано)

Пока в NOVA используется ручной переход на ACE Music. Не добавлять API-ключ в браузер.

Для будущего закрытого сервера определить контракт:

- `POST /api/generations` → `{ projectId, caption, lyrics, durationSeconds, idempotencyKey }`, только у авторизованного владельца.
- `GET /api/generations/{id}` → `{ state: queued|running|completed|failed, duration, errorCode, outputId }`.
- `GET /api/generations/{id}/audio` → приватное аудио в storage; без прямой публичной ссылки на чужой объект.
- Проверки до отправки: права использования ACE API, цена, лимиты, валидация текста, бюджет на аккаунт, один запрос не создаёт дубликат.
- Никакого общего постоянного API-ключа на клиенте. Серверный адаптер должен быть заменяемым: ACE → иной поставщик/собственный инстанс.
- Fail-closed на неизвестный тариф, ошибку API или превышение бюджета. Нет имитации готовой музыки.

Это архитектурное предложение, не рабочая прямая AI-генерация.
