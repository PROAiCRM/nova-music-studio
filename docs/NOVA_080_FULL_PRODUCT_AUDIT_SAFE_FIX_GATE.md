```js
if(field&&hasApplied(field.value)&&field.value.length>MAX)
```
This only blocks >350 characters when the Creative Studio directive prefix exists. Unmodified idea text can still exceed 350 characters while base `songCaption(f)` takes a 350-character prefix. This is a concrete possible silent clipping path.

**NOVA 080's one-line staged candidate** uses
```js

```
on the known inline Creative Studio JS block of `app/index.html` and **only** when the whole original script SHA matches the shipped NOVA 064. The candidate is a **new folder, not a deployment**. `sw.js`, backend code, HTML outside this expression, IndexedDB, music and models remain byte-identical to the archived baseline. This alone does **not** prove other non-click Prepare/keyboard/API code paths are protected; browser and server review are mandatory.
